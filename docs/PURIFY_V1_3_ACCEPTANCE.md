# Purify 1.3.0 开发与验收范围

状态：本地开发版，尚未推送、打标签或正式发布。保留上游包内版本，发布时再按现有 Purify 工作流对齐版本号。

## 界面验收（Android / Windows 均需执行）

1. 视频盾牌页最上方为本视频净化记录，评论与弹幕分别切换、分别显示计数，空记录有明确提示。
2. 评论保留折叠/屏蔽原文和本视频显示操作；弹幕展示最近 200 条原文与命中原因，包含传统关键词、正则、发送者命中。
3. 原“评论名单”“弹幕规则”位置只保留“评论净化”“弹幕净化”入口，下方不再出现同功能助手入口或净化介绍。
4. 从“弹幕净化”进入时仍绑定当前视频；切集后不得串用上一视频的记录。
5. 净化中心返回评论或原页面时不自动回到顶部；配置备份位于净化中心底部，SAF 选择/备份/恢复行为不变。
6. 首页新增“视频净化”标签，与推荐等标签并列；旧标签索引不变，旧用户只迁移一次，之后仍可排序/隐藏。
7. 视频标题过滤与导入导出行为不变；视频页不再有视频关键词入口。标签过滤仅预留入口，本版不请求视频标签。

## 弹幕验收

- 激进乱码过滤默认关闭。启用后，含拉丁字母的弹幕命中任一条件即可临时屏蔽：前后 2 秒孤立、至少两个标点/特殊字符、不在内置常用网络组合表。
- 分段边界前后数据不足时，孤立条件为未知，不凭未知触发；其他已成立的条件仍有效。时间源为弹幕视频时间轴。
- 全局白名单仅由用户确认添加，整条匹配，仅豁免自动判断，不覆盖用户主动设置的关键词/正则/发送者屏蔽。
- 哈哈哈哈显示为哈哈哈、66666 显示为 666；原文仍用于统计、命中预览与关键词提取，不能把显示文本作为学习原文。
- 中文数字时长、英文时间、限定后缀及短符号组合进入模板窗口；单条时间/符号不能因模板规则直接被屏蔽，保留窗口前两条。
- 快捷面板“提取弹幕关键词”可编辑、保留选中内容，确定后按字面包含匹配；空白与取消不保存，重复规则不重复添加。

## 样本与备份验收

- 只在手动添加内容屏蔽规则时收集样本；自动命中和屏蔽发送者不作为内容质量学习证据。
- 原文、提取关键词、匹配方式及重复次数可预览、删除和手动导出；最多 1000 条，去重计数，不自动上传、不自动更新规则。
- 删除样本不应删除已生效的屏蔽词。白名单删除仅撤销放行，不生成屏蔽词。
- 白名单与待学习样本通过现有配置方案备份往返；旧配置导入后激进过滤仍默认关闭。
