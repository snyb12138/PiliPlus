# UP 主黑名单导入导出

屏蔽特化版在“设置 → 黑名单管理”中提供两种入口：

- 右上角下载按钮：分页读取账号侧完整在线黑名单，与本地投稿过滤名单合并，排序去重后导出。
- “本地”标签页浮动按钮：快速导入、导出本地投稿过滤名单，也可使用剪贴板。

文件名形如 `piliplus_blackMids_时间.json`，内容是纯 UID 数组：

```json
[123456789, 987654321]
```

该格式可由 PiliPlus 重新导入，也可直接导入 PiliPlus 屏蔽联动浏览器插件 v0.3.0 及以上版本。导入时兼容 JSON 整数和十进制字符串，非法、非正数 UID 会中止导入并显示所在位置。

完整导出需要登录 Bilibili 账号并联网；未登录时只导出本地名单。若任一在线分页读取失败，导出会停止并提示错误，不会静默生成不完整文件。
